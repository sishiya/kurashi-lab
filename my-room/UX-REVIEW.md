# わが家の模型 — 画面の点検と直し方

2026-10-19。ユーザー「操作が直感的でない・情報量が多くてどれを見てどれを動かせばいいかわかりづらいのを一つずつ潰す。日差しは実際に日の当たり方をシミュレーションできるとわかりやすい。スマホ対応。人間の目線・目の動き・視覚特性・手数・導線・簡単さ・見やすさから、シンプルかつ必要なものが揃っている完璧なアプリを」。
守る約束: あそびラボ RULES 4章（区割り・フィッツ・近接と余白・字は少なく・強調は1つ・すぐ返事・3D の回す向きの逆転・4つの幅で確かめる）。

## 区割り（どこに何を置くか。いつも同じ場所）

| 場所 | 役割 |
|---|---|
| 上の帯 | 名前・「外に送りません」・タブ（図面／3D／WiFi／搬入／日差し）。タブは「いまどの作業か」。部屋がないうちは図面以外を押せない（うすく、押すと理由） |
| まん中（いちばん大きく） | 図または 3D。ふさがない。中に置くのは小さな印だけ: 右上＝北（ドラッグで回せる）、右下＝拡大・全体、左下＝縮尺の棒、左上＝そのタブの状態（縮尺の確かさ・計算中など） |
| 図のすぐ下 | そのタブの道具（1行）→ えらんだものの編集（1行）→ いまやることの一言（1行）。よく押すものほど左・大きく |
| 右の欄（PC）／下（スマホ） | そのタブの結果と、ときどき使う設定。タブで中身が変わる。説明（しくみ・出どころ）は閉じた「このツールについて」に1つにまとめていちばん下 |

## 見つけたこと → 直し方（重い順）

1. 図がタブの切りかえ・画面の大きさで合わなくなる（家がボタンの裏に隠れる・図の外）。3D に切りかえた直後が真っ黒のことがある → 大きさが変わったら、自分で動かしていなければ「全体」に合わせなおす。動かしていれば、まん中を保つ。3D は切りかえたらすぐ描く。
2. はじめに何をするかが図の中にない（空の方眼だけ）→ 図のまん中に「はじめ方」（画像を読みこむ・3D スキャン・見本で試す・方眼に描く）と「ここに画像を落とせます」。右の欄と案内の重複をなくす。
3. 右の欄がタブに関係なく図面の設定のまま。結果（WiFi の強さ・搬入の判定・日あたり）は図の下に押しこまれている → 右の欄をタブごとに入れかえ、結果は右の欄（スマホは図の下）に。めったに使わない設定（家の種類・ひさし・境目・単位など）は右の欄へ。
4. 字が多い（長い説明が最初から全部見える）→ 一言だけ出し、くわしくは「？」で開く。「しくみ」「出どころ」は「このツールについて」にまとめる。
5. やり直しにくい（消す・最初から・スキャンで置きかえ・見本で上書き）→ その場で「元に戻す」つきの知らせ。元に戻す・やり直すのボタンを大きく。
6. タッチで Shift が押せない（まっすぐにそろえるのをやめられない）→ なぞるときに「まっすぐ」の切りかえ。
7. 北の向きが下の欄の数字のつまみ → 図の右上の矢印をドラッグして回す（方位マークに重ねて合わせる）。
8. 3D の回す向きを逆にできない（約束）→ 3D に「回す向き: ふつう／逆」（左右・上下）。
9. 日差しが「黄色い面」だけで、時間で動くようすがわからない → 「▶ 1日を見る」で時刻を自動で進める。3D で、窓から入る日が床を動くのを見る（壁は低く見せたまま、影は天井まである壁と天井で作る）。
10. スマホ: 道具の行が何段にも折り返す・図が小さい → 道具は1行で横にすべらせる、押す所は 44px、結果は図の下。横向きは PC と同じ左右2列。
11. 搬入: 結果のあと、運ぶようすを自分で動かすしかない → 「▶」で玄関から運ぶ先まで動かす。
12. WiFi: 「いちばん良い置き場所を探す」は印がないと押せないのに理由が出ない → 押せないときは理由を一言。

## 直したこと（2026-10-19）
1〜12 はすべて v009-ux・v010-ux2 で直した（中身は `DEVNOTES.md` の「画面の見なおしでしたこと」）。次に見る所: 本物の間取り・スキャンで、はじめての人に触ってもらう（30 秒で何をすればいいかわかるか）。

## 確かめ方
PC 1280×720・1024×768、スマホ 375×740・横 812×375 で、タブごとに screenshot。はじめての人の手順（見本で試す → 図面 → 3D → WiFi → 搬入 → 日差し）を通して、迷う所がないか。
